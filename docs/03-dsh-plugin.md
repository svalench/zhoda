# Слой 3: @zhoda/dsh-plugin — плагин DeepSeek Harness

> Нативный dsh-плагин (TypeScript): визуализация дебатов фракций в веб-UI dsh.
> Витрина проекта внутри самой быстрорастущей агентной экосистемы.
> Тонкий слой: вся логика в zhoda-core, плагин только показывает и вызывает.

## 1. Позиционирование в экосистеме

- dsh открыт 13.08.2026, 186k★ за 10 дней, «всё является плагином» (Cordis)
- Ниша проверена (23.08.2026): council/debate/deliberation-плагинов не существует;
  ближайшие — dsh-crew (ролевая бригада), dsh-agent-messaging (координация сессий)
- Цель: стать первым deliberation-плагином и попасть в awesome-dsh-plugin,
  пока список молодой

## 2. Что видит пользователь

**Панель «Zhoda» в dsh web (localhost:3080):**

1. **Палата дебатов** — живой транскрипт: фракции как «партии» с именами,
   речи раундов, перекрёстные допросы; стриминг по мере хода раундов
2. **Граф фракций** — узлы-модели, группировка по фракциям, анимированные
   переходы («Gemma перешла к Прагматыкам после аргумента DeepSeek о стоимости
   миграции») — главный вирусный элемент для скринкастов
3. **Панель вердикта** — решение большинства, статус `zhoda_reached`,
   minority report в отдельной рамке, карта разногласий
4. **Карта ценности** — что совет уточнил у пользователя перед спором
   (редактируемо: поправил ценность → пересобрал дебаты)

## 3. Архитектура плагина

```
dsh (Cordis runtime)
  └─ @zhoda/dsh-plugin (dsh-plugin)
       ├─ tools: прокси к zhoda-mcp / zhoda-core (HTTP)
       ├─ ui: React-компоненты панели дебатов (слоты UI-плагинов dsh)
       ├─ skills: SKILL.md «когда звать совет» для агента dsh
       └─ storage: ссылки на transcript_id (сами хронікі — в core)
```

- Плагин НЕ содержит логики дельберации — только вызовы и визуализацию
- Связь с ядром: через локальный `zhoda-mcp` (SSE) или напрямую в core API
- Если core недоступен — плагин честно показывает «совет офлайн» и инструкцию
  запуска (`uvx zhoda-mcp`)

- Пин версии dsh в peerDependencies + матрица совместимости в README

- Фичефлаг `ZHODA_DSH_UI=off` — плагин работает как чистый tools-провайдер,
  если UI-слоты поменялись

## 8. Почему этот слой последний, но обязательный

Ядро и MCP дают пользу; плагин даёт **видимость**. Именно визуализация спора
фракций — то, что люди будут скринить и репостить. Conclave показал: UI дебатов
привлекает даже без глубины. У Zhoda будет и глубина, и витрина.
