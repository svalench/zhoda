# Draft invitation — read-only decision review (5–10 volunteers)

**Status: draft. Do not send. Do not publish as an open call.**

This file is for the owner after they have permission to contact people
and, separately, permission for any live model calls.

## What we would ask

You already write ADRs / RFCs / change plans. For 1–2 of **your** docs,
run Zhoda `zhoda_review` (read-only). It does not apply patches, open
issues, or merge anything. You keep the documents.

We will **not** collect your source documents into telemetry by default.
If a run transcript is useful for a later write-up, we ask again, in
writing, before using any excerpt.

## What we will not claim

- That the council is correct because a volunteer said “this was useful.”
- That `short_review` is better than Oxford (eval not live).
- Stars, likes, or NPS as quality.

Time: one review, 10–20 minutes including the form.
